# AI Hand Gesture Controller

A real-time AI-based hand gesture volume controller developed using Python, OpenCV, MediaPipe, and Pycaw. This project uses computer vision and hand tracking to control the system volume through finger gestures captured from a webcam or mobile camera.

## Features

* Real-time hand detection and tracking
* Volume control using thumb and index finger distance
* Dynamic volume percentage display
* Smooth gesture-based interaction
* FPS counter for performance monitoring

## Technologies Used

* Python
* OpenCV
* MediaPipe
* NumPy
* Pycaw

## How It Works

The system detects hand landmarks using MediaPipe and calculates the distance between the thumb and index finger. Based on the detected distance, the program adjusts the system volume in real time.
